EndpointWhat it does
GET api/snapshotEvery image, chart, vulnerability and cluster of the last scan.
POST api/refreshStarts a full scan.
POST api/rescan/image?ref=…Checks every tag of an image again (versions and vulnerabilities).
POST api/rescan/chart?…Checks a chart and its subcharts again.
POST api/administration/…The actions of the Scans and Trivy tab: retry-failed, trivy-db, connectivity.
GET api/administration/unused-imagesImages cached on nodes that no workload uses, per cluster.
GET metricsPrometheus metrics: outdated images and charts, vulnerabilities, clusters, scans.
GET healthz, readyzProbes of the pods.
