{{ icon("cpu") }}CPU and memory recommendations are off

This page compares the CPU and memory requests and limits of every container with what it really uses, as krr recommends from the metrics of Prometheus: what is reserved for nothing, and what is at risk of CPU throttling or OOM kills.

It needs Prometheus (or VictoriaMetrics, Thanos, Mimir) with the cAdvisor metrics of the clusters. With the Helm chart:

krr:
  enabled: true      # runs krr in its own pod and turns resources.enabled on
config:
  resources:
    prometheus:      # optional: krr finds Prometheus in each cluster otherwise
      - clusters: ["*"]
        url: http://prometheus-operated.monitoring:9090
