# Security policy

kube-tower only reads from your clusters and registries: it never creates, modifies or deletes
Kubernetes objects, and it never displays secret values.

## Reporting a vulnerability

Please do not open a public issue. Use GitHub's
[private vulnerability reporting](https://github.com/Arcanexus/kube-tower/security/advisories/new)
instead. You will get an answer as soon as possible.

## Supported versions

Only the latest release receives security fixes.
